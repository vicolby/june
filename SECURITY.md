# Security policy

## Supported versions

Only the latest release receives security fixes. Upgrade to the latest release before reporting an issue.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories:
<https://github.com/vicolby/june/security/advisories/new>

Do not open a public issue or pull request for a suspected vulnerability.

Include the affected june version, the steps to reproduce, and the impact you expect. Expect an acknowledgement of the report, then a fix and a coordinated disclosure through a published advisory.
